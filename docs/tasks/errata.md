## 口径备忘（不是勘误，是实现约定）

| 项 | 约定 | 原因 |
| :--- | :--- | :--- |
| 金额单位 | **账本与积分一律 `_micro`（微积分）**；**支付金额用 `_fen`（分）** | `t_plan.price_fen` 按 TDS 定义即「分」。若统一要求 `_micro`，会把"99 元"写成 99000000 微积分，支付网关对账反而易错。T04 的「禁浮点/禁 decimal」grep 需按此区分，不得把 `_fen` 判为违规 |
| 距离/比率 | 倍率、比率一律整数万分比（`*_bp`） | 与 `cost_micro` 的整数口径一致；decimal 在 Lua 与整数混用会引入隐式转换误差（TDS §1.4） |
| 「无上限」 | 用 `NULL`，不用 `0` / `-1` | `0` 在额度语义下等于"不能用"；`-1` 需要额外分支判定 |
