## 1. 事实（已核，勿重复调查）

## 2. 要做（六条，按序）

1. **`POST /api/admin/models` 支持随模型建默认路由**
   在 `modelCreateRequest`（`internal/control/ops/model.go:96`）新增两个可选字段：
   - `upstream_model_name *string` — 上游真实模型名（如 `qwen-plus`）
   - `stream_supported *bool` — 该路由是否支持流式，缺省 `true`

   语义：**给了 `upstream_model_name` 且给了 `primary_channel_id` 时**，在同一事务内用 `insertRoute` 建一条默认路由（weight 100 / priority 100 / max_tokens_ceiling 0 / enabled 1），`region` 取该渠道的 `region`（不要用请求里的 region，避免与渠道不一致）。
   只给 `upstream_model_name` 没给渠道 → `400 invalid_field(primary_channel_id)`，不要猜。
   都没给 → 维持现状（只建模型，不建路由）。
   事务提交后若建了路由，调用 `s.publish(ctx)`。

2. **新增 `internal/control/ops/route.go`，实现四个端点**

   | 方法 | 路径 | 行为 |
   | :--- | :--- | :--- |
   | `GET` | `/api/admin/routes` | 分页列表；支持 `model_id`、`channel_id`、`enabled`、`region` 过滤；返回字段见 §2.3 |
   | `POST` | `/api/admin/routes` | 建一条路由；**唯一键已存在 → 409 `resource_state_conflict`**，不要复用 IGNORE 语义静默成功 |
   | `PATCH` | `/api/admin/routes/{id}` | 改 `upstream_model_name` / `weight` / `priority` / `stream_supported` / `max_tokens_ceiling` / `enabled` |
   | `DELETE` | `/api/admin/routes/{id}` | 物理删除；**若该模型当前是 `LISTED` 且删的是它最后一条 `enabled=1` 的路由 → 409**，提示先下架或先建替代路由 |

   所有写操作成功后 `s.publish(ctx)`；读操作不 publish。

3. **字段与校验**
   - 建/改路由：`model_id`、`channel_id`、`protocol_id` 必须存在且模型、渠道均未软删；`protocol_id` 缺省取渠道的 `protocol_id`。
   - `upstream_model_name` 去空白后 1..128 字节，空则 `invalid_field`。
   - `weight` 0..10000、`priority` 0..32767（`smallint`）、`max_tokens_ceiling >= 0`，越界 `invalid_field`。
   - `region` **不接受请求入参**，恒取渠道 region（见 §1 事实）。
   - 删除/修改不存在的 id → 404 `resource_not_found`。

4. **注册到 `internal/control/server.go`**
   放在渠道路由组附近（`/api/admin/channels` 那一段之后），权限统一 `mw.PermModelWrite`（与 `RegisterUpstreamModels` 一致：路由是"模型上线配置"，不是渠道自身属性）。

5. **`api/openapi.yaml` 同步**
   把四个新端点与 `modelCreateRequest` 的两个新字段写进 spec。**本仓库 openapi 已明显滞后，本次新增的必须进 spec**，不要再欠账。

6. **补测试**（`internal/control/ops/route_test.go`）
   - 建模型带 `upstream_model_name` → `t_route` 恰好 1 条，`region == channel.region`，且快照被 publish（可用 fake publisher 断言被调用）。
   - 建模型只给 `upstream_model_name` 不给渠道 → 400。
   - `POST /routes` 重复同一组唯一键 → 409。
   - `DELETE` 模型处于 `LISTED` 且为最后一条启用路由 → 409；先把模型改 `CATALOG_ONLY` 再删 → 200。
   - `PATCH` 改 `enabled=false` 后快照重发（断言 publish 次数）。
